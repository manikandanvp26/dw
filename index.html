01 — Project Overview

From raw events to decision-ready data — in seconds, not days.

Modern e-commerce and healthcare organizations generate massive, heterogeneous, high-velocity data — clickstreams, transactions, IoT device readings, EHR events, and third-party APIs. Traditional batch warehouses cannot keep pace.

This project presents the design and development of a real-time data warehouse with a comprehensive preprocessing layer: ingestion, cleansing, deduplication, schema enforcement, and enrichment — orchestrated end-to-end and served to BI/analytics consumers with sub-second freshness.

The solution was validated on two demanding domains: real-time e-commerce analytics (funnels, inventory, personalization) and healthcare operational analytics (patient flow, equipment telemetry, compliance reporting).

  • /01

    Lambda → Kappa Stream Architecture

    Unified streaming-first design eliminating dual-path complexity and reconciliation drift.

  • /02

    Automated Data Quality Gates

    Great Expectations–style validation at every stage; quarantine path for poisoned records.

  • /03

    Change Data Capture Integration

    Debezium-based CDC keeps OLTP systems and the warehouse continuously synchronized.

  • /04

    Cost-Aware, Schema-Evolved Storage

    Medallion layout (Bronze → Silver → Gold) with partitioning, clustering, and auto-compaction.

02 — System Architecture

End-to-end streaming pipeline, engineered for resilience.

Five logical layers — source capture, stream transport, preprocessing, warehouse storage, and serving — decoupled via durable message queues so every component scales independently.
